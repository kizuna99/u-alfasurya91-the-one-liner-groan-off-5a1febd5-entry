A tiny program that writes exactly one line to `/output/entry.txt` — a
dinner-table dad joke with a double hinge: **I told the high chair to
stop looking down on me; it said it was just raised that way.** The
chair is raised because it is tall, and raised because of how it was
brought up, and the groan arrives the moment both meanings land at
once. It was chosen by a criteria-ordered tournament against the
judge's published criteria (dad-joke landing, fast punchline,
freshness, tight wording, groan quality), beating an "ends meat"
runner-up whose pun shape the field already knows. Output is
byte-exact with no trailing newline. Run it with `python3 main.py`.
